# TrapLight LaserBase 0.7.0

Первый публичный тестовый выпуск. Windows x64, Portable и Setup.

На заставке программа проверяет новые версии в официальном репозитории GitHub. Если найден новый выпуск с portable-архивом и SHA256SUMS.txt, появляется кнопка Update. Проверка не блокирует запуск; без интернета можно продолжить работу.

Update требует подтверждения, проверяет SHA-256 загруженного архива и сохраняет полную приватную копию .lbbackup в Документы/TrapLight LaserBase Backups. Затем программа закрывается, заменяет только файлы приложения и запускается снова. SQLite-база, фотографии, миниатюры и Peer ID остаются на месте. Прежние заменённые файлы программы сохраняются в .update/<идентификатор>/previous-program. При обычной ошибке копирования выполняется откат; сведения об ошибке показываются при следующем запуске. Не прерывайте питание во время замены файлов.

Установщик работает для текущего пользователя, создаёт ярлык в меню «Пуск» и при желании на рабочем столе. Обновление через установщик и его удаление не удаляют созданные пользователем data, images, thumbs, network. Для переустановки укажите прежнюю папку. Резервную копию перед ручным удалением папки делайте отдельно.

Полная база материалов начинается с экспериментов пользователей; готовых проверенных изготовителем настроек не заявлено. Программа хранит настройки, но не управляет лазером. P2P работает по вручную указанному адресу: автоматического поиска устройств и поиска по всей сети пока нет. Реальный тест между двумя компьютерами ещё нужен.

Сохранение и восстановление всей базы: Экспорт / печать → Сохранить базу в один файл / Восстановить из файла. Личная резервная копия содержит ключ Peer ID — не публикуйте её. При восстановлении программа закрывается; запустите снова.

В поставку включены лицензии Qt и MinGW. Исходники LaserBase не публикуются; архивы исходников библиотек Qt размещаются отдельно для выполнения их лицензий.
